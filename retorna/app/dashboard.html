✈️ Conexión con Telegram Bot

Los conductores y supervisores interactúan por Telegram. Cada mensaje que reporta una entrega, recogida o alta de proveedor se guarda de inmediato en la base de datos SQL de Supabase.

ENDPOINT WEBHOOK DE TELEGRAM
POST /api/telegram/webhook
📋 Comandos rápidos del bot:
  • /proveedores — Lista los proveedores en Supabase
  • /nuevo_proveedor Nombre | Contacto | Tel — Registra proveedor en SQL
  • /eliminar_proveedor ID — Elimina proveedor en SQL
  • /entrega ID_PROV TIENDA PEQ GRD — Registra entrega en tabla SQL
  • /recogida ID_PROV TIENDA PEQ GRD — Registra recogida en tabla SQL
  • /saldo TIENDA — Consulta saldo y % no retorno
  • /criticas — Alerta de tiendas prioritarias
PARA CONECTAR TU BOT REAL EN TELEGRAM:

1. Crea tu bot en Telegram con @BotFather y copia el Token.
2. Ponlo en tu archivo .env: TELEGRAM_BOT_TOKEN=tu_token.
3. Ejecuta en terminal: python -m app.telegram.bot (polling directo).
